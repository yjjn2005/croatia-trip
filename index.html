업로드하신 3개 자료(엑셀 일정표, 은퇴부부 PDF 보고서, 유튜브 요약 이미지)를 하나의 동선으로 통합했습니다. 출입국은 자그레브 IN · 두브로브니크 OUT(오픈조 항공)으로 역주행 없이 남하하며, 각 날짜마다 지도·장소·주소를 바로 내비게이션 앱에 붙여넣을 수 있게 정리했습니다.

STEP 1 — 자료 종합

업로드하신 3개 자료, 이렇게 다릅니다

엑셀·PDF·이미지(유튜브 요약) 세 자료는 도시 구성과 우선순위가 조금씩 달랐습니다. 아래는 각 자료의 핵심과, 이를 어떻게 합쳤는지 정리한 결론입니다.

자료① 엑셀

크로아티아 7일 자유여행 (남부 골든루트)

  • 자그레브 → 플리트비체 → 자다르 → 스플리트 → 흐바르 → 두브로브니크
  • 도시 간 버스·페리(카타마란) 이용, 렌터카 불필요
  • 숙소·맛집 평점 리스트가 상세함 (호텔 예제로, 코르나로, 흐바르 등)
자료② PDF

은퇴부부 6박7일 (오픈조 항공 설계)

  • 두브로브니크 IN → 스플리트 → 자그레브 OUT, 역주행 없는 동선
  • 플리트비체는 시간 부족으로 제외, 대신 시니어 보행 동선(하루 5~8km) 설계 상세
  • 엘리베이터·평지 위주 숙소, 오전 성벽투어 등 체력관리 팁 풍부
자료③ 이미지 요약

11월 1일 출발, 동계 비수기 전용차량 일정

  • 자그레브 → 라스토케 → 플리트비체 → 자다르 → 스플리트 → 스톤 → 두브로브니크
  • 도어투도어 전용차량(데이트립 등) 이용, 짐 걱정 없는 이동
  • 일몰·동계 운영시간(성벽 09~15시 등) 반영이 정교함
통합 결론 — 자료③의 전용차량 도어투도어 동선(자그레브→라스토케→플리트비체→자다르→스플리트→말리스톤→두브로브니크)을 뼈대로 삼고, 자료①의 숙소·맛집 리스트를 채워넣었습니다. 자료②의 은퇴부부 체력관리 원칙(평지 위주, 엘리베이터 숙소, 성벽은 오전, 하루 60~90분 휴식, 스플리트·두브로브니크 2박 연박)을 전 일정에 적용해 부부 두 분께 무리 없는 7박8일로 재구성했습니다.
